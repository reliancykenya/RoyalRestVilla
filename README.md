# Royal Rest Villa — One Page WordPress Theme

A bespoke, plugin-free WordPress theme for **Royal Rest Villa**, designed as a fast single-page hospitality website.

## One-page flow

Home → The Villa → Rooms → Amenities → Gallery → Reviews → Booking → Contact

The primary navigation uses anchors and keeps visitors on the homepage. Rooms and testimonials are managed in WordPress Admin but are rendered into the one-page experience rather than requiring separate public pages.

## Included

- Quicksand typography and responsive luxury hospitality design.
- Ivory, charcoal, royal-gold and deep-forest colour system.
- WordPress Customizer controls for colours, copy, hero/about images, amenities, gallery, contact details, booking configuration and SEO.
- Editable WordPress one-page menu with a built-in anchor fallback.
- Admin-managed Rooms and Testimonials.
- Native booking form embedded on the homepage.
- Booking references, confirmation emails, booking status workflow and basic room/date conflict checking.
- WP Admin → Bookings for Pending, Confirmed, Checked-in, Completed and Cancelled requests.
- Native SEO: title/meta controls, canonical URLs, Open Graph, Twitter Cards, robots.txt and WordPress XML sitemap.
- Hotel/LodgingBusiness, WebSite, WebPage, HotelRoom, Offer, amenity and geo structured data.
- /llms.txt endpoint for machine-readable property discovery.
- Responsive gallery with lightbox.
- WhatsApp shortcut and contact/location section.
- No plugin dependencies.

## Install

1. Download or clone this repository.
2. Place it in wp-content/themes/royal-rest-villa.
3. Activate **Royal Rest Villa** under Appearance → Themes.
4. Upload the approved logo under Appearance → Customize → Site Identity.
5. Open Appearance → Customize → Royal Rest Villa and configure Brand & Colours, One Page Content, Amenities, Gallery, Contact & Social, Booking, and SEO & AI Discoverability.
6. Add room cards under **Rooms**.
7. Add guest reviews under **Testimonials**.
8. Optionally create a WordPress menu using custom links such as #about, #rooms, #gallery, #reviews and #contact. If no menu is assigned, the theme provides the correct one-page navigation automatically.
