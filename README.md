# Royal Rest Villa WordPress Theme

A bespoke, plugin-free WordPress theme for **Royal Rest Villa**.

## Included
- Responsive luxury hospitality design using Quicksand.
- Native WordPress Customizer controls for branding, colours, homepage copy, contact details, booking email and SEO defaults.
- Rooms and Testimonials content types.
- Native booking request form that stores submissions in **WP Admin → Bookings** and emails the property and guest.
- Per-page/post/room SEO title, meta description, social image and noindex controls.
- Canonical, Open Graph, Twitter Card, LodgingBusiness and HotelRoom JSON-LD markup.
- Native WordPress XML sitemap and optimized robots.txt.
- No plugin dependencies.

## Install
1. Download/clone the repository and place it in `wp-content/themes/royal-rest-villa`.
2. Activate **Royal Rest Villa** under Appearance → Themes.
3. Upload the approved Royal Rest Villa logo under Appearance → Customize → Site Identity.
4. Configure colours, hero image, copy, contact details, booking email and SEO under Appearance → Customize → Royal Rest Villa.
5. Create the main navigation under Appearance → Menus.
6. Add rooms under **Rooms** and testimonials under **Testimonials**.
7. The theme creates a `Book Now` page automatically on first activation. If needed, create a page manually with shortcode `[rrv_booking_form]` and slug `book-now`.

## Recommended palette
- Ivory: `#FFFDF8`
- Charcoal: `#171717`
- Royal Gold: `#C79A24`
- Deep Forest: `#26362B`
- Mist: `#EEF6F2`

These colours complement the black-and-gold Royal Rest Villa identity while giving the site a calm countryside-luxury feel.
